# GSAP 首页与工作台提升结果

先制定 [动效方案](GSAP_MOTION_PLAN.md)，再按官方 GSAP React、时间线、ScrollTrigger 与性能规范实施。使用 `gsap@3.15.0`、`@gsap/react@2.1.2`，具体版本记录在 lockfile。

## 已实现

- 首页：语言轨道以独立包装层完成聚焦出场，品牌和进入提示同步呈现；欢迎序列最长 700ms，期间仍可进入工作台。
- 滚动介绍：一个 ScrollTrigger 时间线平滑驱动三个介绍步骤和结尾。保留原生滚动，每次聚焦一段；阅读阶段压暗背景，文字避开底部进入提示。手机使用 327px 内容宽度（375px 视口），替代原本 27vw 的窄列。
- 工作台：标题、实际状态数字、下一项任务、订单队列按优先级协调出现，400ms 内完成。数字始终使用实际业务值，不从零计数，也不延迟按钮可用性。
- 浮层：公司、角色、客户、语言、单位共用触发方向感知的 180ms 菜单动效；弹窗使用 220ms 的背景/前景协调出现。保留键盘选择、焦点循环、Escape 和即时关闭，移除旧弹窗 CSS 入场动画以免冲突。
- 生命周期：`useGSAP` 配合 scope、matchMedia 和自动 revert。隐藏页面时完成短动效，暂停首页视频、鼠标和滚动触发器；离开首页时释放 ScrollTrigger。

保留现有字体、视觉样式、星云无缝循环、语言轨道物理和鼠标弹簧。没有恢复滚动进入工作台、没有添加减少动效按钮、没有修改业务权限和 API 请求逻辑。

## 性能与范围

动画以 transform、opacity 和小范围文字裁切为主；不动画布局尺寸，不创建额外持续循环或永久 will-change。ScrollTrigger 留在延迟加载的首页 chunk。主包 gzip 约 66.2kB，首页 chunk gzip 约 25.4kB；原 Three.js chunk 不变。

上述为桌面浏览器实测与手机视口模拟。减少动态效果和隐藏页面通过隔离测试页模拟；未声称验证实体手机、Safari、真实系统设置切换、电池消耗或设备 FPS。入口远程背景媒体仍受网络可用性影响。
