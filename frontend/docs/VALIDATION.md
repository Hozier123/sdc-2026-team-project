## 浏览器实际验证

使用 Tabbit skill 进行语义定位和点击验证，覆盖：

1. 原 HTML 滚动到进入按钮，点击 **Explore KiraOrder** 后进入主页，起始动画 iframe 随即卸载。
2. 常规订单：选择客户 → 输入两行消息 → 创建草稿 → 批准生成 DO → 刷新恢复同一完成页 → 查看审计。
3. 规格疑点：美禄 1kg / 2kg 选择 → 记住客户说法 → 未保存时批准仍禁用 → 离开时提示保留修改 → 保存后批准启用。
4. 议价：人工输入 RM95 与改价理由 → 保存后显示 RM475 → 跟单员送老板 → 草稿锁定 → 老板查看原因并批准生成 DO。
5. 驳回：无理由时按钮禁用 → 逐字输入理由时焦点保持 → 驳回后显示已记录决定和理由。
6. 仓库：切换仓库角色 → 按 DO 号码查询 → 只显示拣货信息，不含 RM 金额或新建操作。
7. 搜索 Ayam 得到对应订单 → 缺货数量 5 改为 3 → 保存解除阻断 → 批准出单。
8. 打印媒体样式：侧栏与操作区为 `display:none`，送货单正文保留。未调用系统打印对话框或生成实体 PDF 文件。
9. 生产构建上再次执行手机核对、保存和批准路径。

## 自动回归范围

- 精确分币核价；价格格式校验。
- 手机号、邮箱、证件号在保存前掩码。
- Unicode code point 证据片段（含 emoji 代理对）。
- 规格疑点、单位缺失、客户记忆作用域。
- 缺货减量解除、再次加量重开、同 SKU 多行累计库存。
- 价格不自动应用、目标行必填、议价与行级覆盖价一致性。
- 保存失败不泄漏别名写入。
- 老板权限、审批绑定版本、驳回理由与终态。
- 提交后库存变化不能被老板绕过。
- 仓库响应字段裁剪与接口隔离；跨租户不可见。
- 并发服务实例读取最新版本，旧版本保存与批准被拒绝。
- 空订单、只读金额写入、重复批准被拒绝。
- Gate 0 parse、审批 202、409 错误与请求 ID、审计事件、分页适配。
- API 连接拒绝非本机明文 HTTP 和 URL 内嵌凭证。
