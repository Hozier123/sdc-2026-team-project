# KiraOrder 网页细节设计方案

本轮目标：让使用者进入工作台后，能迅速判断哪些订单需要处理、从哪里开始，以及每次操作的结果。以现有 React 19 + Vite + Tailwind v4 项目为基础，保留星球开场、深色工作区和薄荷绿品牌。

## 视觉基础

| 角色     | 色值    | 用途           |
| -------- | ------- | -------------- |
| 背景     | #090e15 | 页面底色       |
| 表面     | #101720 | 列表和内容区域 |
| 正文     | #e1e8ed | 主要内容       |
| 次级正文 | #97a6b5 | 辅助说明       |
| 主要操作 | #94e3bd | 新建和确认     |
| 需要处理 | #dfbd85 | 阻塞检查       |

状态色延续现有蓝色和玫瑰色。Cormorant Garamond 用于页面标题，Arial 与系统字体用于信息密集的业务内容。数字使用等宽数字特性，正文左对齐。间距使用 8、16、24、28px；触控按钮至少 44px；响应反馈 160ms，常规过渡 220ms。

设计评估：UI/UX 搜索返回的蓝橙配色与营销页结构不适合现有订单产品，因此仅采用其功能性布局与可访问性建议。视觉重点继续放在开场页；工作台强调订单状态和后续操作。

## 页面结构

```text
桌面：侧栏 | 页标题、日期、待处理摘要       新建订单
           | 四种状态统计（数量 + 操作说明）
           | 开放订单列表                 下一单与检查说明
           |                              最近活动

手机：顶栏与可关闭导航
      标题、摘要、新建入口
      两列状态统计
      订单列表
      下一单、活动
```

## 已落地的细节

- 总览增加待处理摘要、统计操作说明、列表说明和下一单的处理理由。
- 下一单优先选择最早收到的待解决订单，其次是最早的待审批订单，移除固定产品关键词偏好。
- 收件箱以路由驱动筛选，支持刷新和前进后退；保留搜索输入，切换筛选时不清空输入。
- 筛选使用带按下状态的原生按钮组；新增搜索结果播报、清空筛选和无结果恢复入口；Escape 清空搜索。
- 弹窗标题使用独立 ID；手机导航支持焦点约束、Escape 关闭和焦点恢复，打开时背景不可交互。
- 统一移动端客户名称和消息字号、状态说明、聚焦样式及数字排版；搜索栏可占满可用宽度。
- 开场增加独立暂停按钮；视频与 3D 同时暂停；遵循系统减弱动态效果设置，暂停期间按需渲染。

## 背景循环动效补充

背景视频使用双层交替播放，在片尾与下一轮片头之间进行最长 1.6 秒的平滑交叉淡化。当前层保留到下一层完成淡入，再重置并预备下一轮；下一层缓冲时保持当前画面，避免黑屏。逐帧混合由媒体时间驱动，不触发 React 逐帧更新。

星云加入 16 秒往复漂移，光雾分别以 10 秒、14 秒闭合路径起伏；轨道旋转增强并加入轻微倾斜摆动。暂停按钮同时控制两个视频、光雾、星云和轨道，系统减弱动态效果设置继续生效。

动态强度调整：背景播放速度 1.2 倍，背景位移由约 1% 增至 6%，缩放范围调整至 1.06–1.18，光雾位移增至 18%；轨道基础转速调整为 0.20 rad/s，倾斜摆动更明显。头尾交叉淡化与暂停逻辑保留。

## 自动播放问题修复（以本条为准）

移除动效按钮后，旧代码仍把系统 `prefers-reduced-motion: reduce` 映射为视频暂停与 3D 按需单帧渲染。实际浏览器默认命中该设置，导致两个视频均停在第 0 秒。按用户持续播放的要求，开场页现在默认播放视频、星云和 3D，不再用该系统设置暂停开场；业务工作台原有减弱动态效果规则保持不变。按钮不恢复。

## 初始页弹簧与鼠标跟随

选择与场景直接相关的交互点：薄荷细环鼠标、问候语悬停、星云与镜头视差、底部进入提示吸附。保持原色与字体，不新增面板或控件。

- 鼠标内点实时跟随，外环以刚度 220、阻尼 23 跟随；悬停展开、按下压缩。
- 问候语悬停缩放使用刚度 240、阻尼 17，产生小幅超调与自然回弹；悬停时轨道减速以方便阅读。
- 背景与镜头使用较柔和的弹簧，小幅反向移动，增强空间层次。
- 鼠标靠近进入提示时轻微吸附，离开后回正。
- 原生弹簧积分采用有界时间步长；逐帧直接更新 DOM 与 3D 引用，不逐帧更新 React 状态，也不增加动画库依赖。
- 自定义鼠标仅在精细鼠标设备生效；离开窗口或使用 Tab 时隐藏，进入业务页后卸载并恢复原生鼠标。触屏不显示自定义鼠标。
- 新增弹簧数值稳定性与跨刷新率测试，合计 53 项测试通过。

## 公司选择器

原生下拉改为与侧栏一致的深色浮层：当前公司采用选中底色和勾选，两家公司采用独立缩写头像；面板说明公司之间的订单与审批数据独立，当前为演示数据。使用完整按钮作为展开入口，支持上下方向键、Home/End、Escape 与焦点恢复。浮层挂载到 body 避免侧栏滚动裁剪；切换公司继续执行未保存内容保护。

## 角色选择器与公司菜单精简

角色切换使用与公司切换一致的深色浮层，三个角色分别显示图标、职责短句与当前选中状态。两类选择器共用浮层定位、键盘导航、关闭和焦点恢复逻辑。公司菜单底部的演示数据说明已按最新要求移除。浏览器验证三个角色、公司切换、键盘操作和 375px 手机视口通过。

## 新建订单页比例

页面标题调整为 42px，分区标题 24px，正文 13–14px，步骤标签 12px。主要内容最大宽度 1200px，桌面示例栏 300px，表单与示例顶部对齐；输入框默认高度 220px，手机端 200px。去掉重复的可见 Customer 字段文字，保留其可访问标签。窄屏改为单列表单与四列步骤条，示例区移到表单下方。生产构建通过；在应用内浏览器完成桌面与 375px 手机截图检查，未发现横向溢出。

## Editorial New 默认界面字体

已从字体官方产品页公开提供的字体资源下载正体、斜体两份 WOFF2 可变字体，并在 `public/assets/editorial-new.css` 中本地注册。`--font-ui` 统一导航、统计标签、菜单、按钮、表单、正文，以及原先明确指定 Arial 的局部文字；现有 Cormorant Garamond 标题与装饰符号保留。中文回退到系统中文字体。

正体字体在 HTML 预加载；日常运行不依赖第三方字体 CDN。来源和授权说明记录在 `public/assets/fonts/EDITORIAL-NEW-SOURCE.md`。生产构建通过，浏览器检查默认界面字体为 Editorial New，无页面错误和横向溢出。

## 默认界面字体改为 Cinzel（当前生效）

默认界面字体由 Editorial New 替换为 Cinzel，原有标题字体保留。Cinzel 可变字体（400–900）与 SIL OFL 许可证从 Google Fonts 官方仓库下载，本地加载并预加载正体文件；已移除上一版 Editorial New 的字体与样式资源。手机订单状态标签允许在原列宽内换行，避免 Cinzel 较宽字形挤出布局。生产构建通过，桌面与 375px 手机页面无横向溢出。

字体来源：https://github.com/google/fonts/tree/main/ofl/cinzel
许可证：public/assets/fonts/Cinzel-OFL.txt

### 统计卡与说明文字分开用字

保留四张统计卡标题的 Cinzel 字形和原有数字字体。界面正文、说明、提示及表单使用支持正常大小写的 Arial／系统中文字体，避免 Cinzel 的小型大写字形让整页说明看起来全部大写。通过 `--font-accent` 与 `--font-ui` 分开管理；原有展示标题字体保持不变。

## 默认界面字体统一为 Marcellus（当前生效）

统计卡、导航、按钮、表单和说明文字统一使用 Marcellus 普通版，保留正常大小写；原有 Cormorant Garamond 展示标题与数字字体保持不变。字体和 OFL 许可证来自 Google Fonts 官方仓库，本地加载并预加载正体文件，替换入口原有的 Cinzel 加载。
