# 业务页面视觉统一验收

日期：2026-10-22（Asia/Shanghai）。使用 tabbit 在本地生产预览中验证，数据均为独立预览端口上的合成样例。

## 统一规则

- `src/business-ui.css` 集中定义业务界面的圆角、字号、操作高度、间距和状态色，覆盖已有响应式样式。
- 操作、文字操作、返回、筛选与条件选择按钮使用与左栏相同的 `999px` 胶囊圆角；独立图标操作使用圆形。桌面主要操作高 42px，手机文字及图标操作最小高度为 44px。
- 业务页标题沿用衬线字体，操作和正文沿用无衬线字体；主要正文与按钮 12px，辅助文字 11px，统一行高和区块间距。
- 浅绿色表示可执行的主要操作和成功，琥珀色表示待核对，蓝色表示待老板处理、只读和访问限制，粉红色表示驳回和错误。状态保留文字标签。
- 移除业务区 `Connect your API`，侧栏 `Connect API` 保留。
- 手机送货单明细提高到 11px，元信息为 9–10px；打印规则仍使用原有纸张布局。

## 实际检查

| 范围 | 结果 |
| --- | --- |
| 主页、新建、订单列表、核对、审批列表及详情、送货单列表及详情、活动、仓库 | 360 / 390 / 768 / 1024 / 1440px 均无横向溢出 |
| 操作按钮、筛选、状态标签、表单、底部操作栏、送货单单元格 | 检查圆角与文字越界；主要操作保持浅绿色，次要操作保持深色 |
| 手机新建 → 核对 → 批准 → 送货单 | 实际点击通过；核对按钮圆角 999px，高 44px，字号 12px |
| 跟单员审批详情 | 显示只读说明，不显示批准按钮 |
| 老板驳回 | 无理由时禁止提交；提交合成理由后，结果提示为粉红色 |
| 仓库拣货 | 五种宽度均无溢出，不显示价格 |
| 加载 | `role=status`、`aria-live=polite`，区分工作台和客户加载文案 |
| 空列表 | 订单、审批、送货单均显示统一空状态；订单活动为空时也提供说明 |
| 503 报错 | 显示错误与请求 ID；胶囊重试按钮实际再次发起请求 |
| 403 无权限 | 蓝色锁图标提示，说明联系负责人，不显示无效重试按钮 |
| 401 会话过期 | 提示通过侧栏重新连接，不显示无效重试按钮 |
| 打印媒体 | 隐藏侧栏和操作区，送货单保留，页面白底 |

服务异常、无权限和会话过期由浏览器拦截本机测试请求模拟，只使用虚构令牌；未连接真实 API。手机检查为浏览器视口模拟。

`npm run build` 通过；`npm test` 21/21 通过。已验证路径未捕获页面运行时错误。
