# 停滚后的完整阅读状态

## 问题与修复

文字、透明度和入口位置原来都绑定 ScrollTrigger scrub 时间轴。用户停在入场、离场或两段之间时，页面会永久停留在放大、裁切、半透明甚至没有正文的状态。

现在保留背景、语言场和遮罩的连续滚动视差；文字与工作台入口改成独立的时间动画：

- 原生滚动到 18/40/62/84% 时选择下一段，向上滚动按相同阈值还原。
- 当前章节保持完整可读，直到下一阈值。移除首屏 8–18% 的放大离场、正文的 scrub 进出区间与章节之间的空白间隔。
- 文字以轻量纵深在 360ms 内入场，入口在 440ms 内就位。停止滚轮不会暂停这两项动画。
- 新章节到达时取消旧章节的入场并隐藏旧文字，最终只留下最新章节。快速反向滚动没有待播放的旧动画队列。
- 动态创建的动画通过 matchMedia Context.add 纳入清理；隐藏页面时直接完成短动画，卸载时清除监听、过渡动画和 ScrollTrigger。
- 刷新布局和断点改变时直接恢复当前章节的完整状态。欢迎动画只清除入口的 opacity，不再误清除由入口移动动画控制的 transform。

使用 `data-chapter-motion="moving|settled"` 标识可观察的过渡状态。它不增加产品界面控件。

## 验证

- 在临时浏览器验证页分别停在约 10%、21%、36%、43%、57%、65%、79%、87%、94%。每次等待 settled 后，只有一个可见阅读平面，opacity 为 1，局部 transform 为单位矩阵。
- 10% 对应用户截图中的旧放大离场区间；现在首屏标题和产品介绍完整显示，未继续放大或裁切。87% 的结尾入口可自行完成迁移。
- 快速执行 87%→21%→65%→43%，最后完整显示 Rules check.；后台暂停时过渡直接完成；离开首页后 ScrollTrigger、启用的 trigger 和活跃 GSAP 动画均为零。
- 桌面 1440px 和手机 390px 额外复查。截图和可观察状态在 `docs/evidence/intro-settle/`，临时验证入口在测试后删除。
- 本地完整测试 57/57 与生产构建通过；发布 checkout 的完整测试包含上游新增用例。停止区间回归测试取代旧的 scrub 阅读窗口测试。
- 两个修改实现文件的 Taste 源码 lint 为 0 FAIL、0 WARN；未运行其独立浏览器 inspector，不据此宣称整站审查通过。

本记录覆盖早期深度/收尾方案中对文字与入口 scrub 区间的描述。三层空间、星云视频、现有字体、光标和主动进入工作台的行为保留。
