## A01：拣货结果

合并仅发生在相同商品、单位、拣货要求的行，不修改已批准送货单。不同单位或拣货备注的行仍保留独立身份。合并逻辑有自动测试覆盖，浏览器实际跑通新建、批准、送货单、仓库查询。

## A02 与 A06：资源隔离

`useResource` 增加启用控制及依赖范围校验，切换服务、租户或角色时不展示上一范围的数据。身份确认后，各资源独立启动。活动摘要失败显示局部错误；审批失败只影响审批页；AI 状态检查中或失败不会阻止订单与仓库。

复验采用浏览器拦截的本机模拟 API：活动、审批 503；AI 状态挂起；仓库身份及查询响应。未连接真实服务，也未把失败资源当作正常空列表展示。

## A03 至 A05：异步与保存

引入请求代次保护，离开页面、切换服务或关闭连接弹窗使旧 UI 回调失效。创建成功仍刷新列表，用户可以查找已创建草稿；没有宣称客户端离开等于撤销服务器写入。

核对区使用禁用 fieldset，保存时统一锁定可写项。数量错误在字段旁提示并禁用保存；HTTP 层还会在 JSON 序列化之前拒绝无效数值。正常 nullable 人工覆盖语义保留，没有把所有 null 强制改成数量。

## A07：冲突恢复

恢复入口改为 `Review latest version`。用户可取消并继续保留原编辑、保留编辑并加载最新版、或明确放弃编辑。保留时，未改动字段跟随服务端最新值，新加的服务端行保留；选择商品时相关规格、单位作为一组保留。重新保存前仍显示未保存状态，不自动批准或提交。

若被编辑商品已被其他人删除，或订单已经锁定，保留操作给出说明，原编辑不会消失；用户仍可取消或明确放弃并加载最新状态。对应合并、删除及锁定情形有自动测试。

## A10：兼容页与当前首页

当前项目在本轮修复开始前已采用 `PlanetGreeting` 3D 首页。本轮保留该实现，不退回旧版。`public/intro.html` 继续作为 70% 缩放兼容入口，并独立验证本地字体、背景及进入桥接。

字体不再请求第三方字体 CDN。旧页面的脚本、样式、背景可单独缓存，变更文案不再携带整份 base64 资源。原始桌面参考 HTML 保持不变。

当前 3D 首次加载代码仍约 949 KB（gzip 约 256 KB），保留构建工具的体积提示；它已与约 310 KB 的业务入口 JS 分离。没有测量真实移动网络秒数，也没有把纯 HTML 的缩减比例当作整体页面提速比例。远程背景视频及封面沿用已有设计，未下载或重新托管。
