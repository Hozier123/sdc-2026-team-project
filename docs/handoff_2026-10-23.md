## 3. AI 服务形态（回应 He 的第 2 条）

**不存在 `POST /api/v1/extract`，也不应新增。**

- Gate 0 `contracts/openapi.yaml` 的对外入口是 **`POST /orders/parse-draft`**，且 `test_openapi_parses.py::test_openapi_parses_and_has_exact_contract_paths` 断言 **path 集合完全相等** —— 新增任何路径都会让该契约测试变红。
- AI 模块是**进程内 Python 模块**，由后端在 `parse-draft` 内部调用：

```python
from backend.ai.adapter import OrderAiAdapter

adapter = OrderAiAdapter()                      # 进程级单例，构造时加载 H1/H5 词表
out = await adapter.adapt(masked_text, catalog) # catalog 必须显式注入，禁止 None
# out.lines / out.conditions / out.ai_mode / out.ignored_spans
```

- AI 只产出 **Pre-Resolver** 结构：`lines`（含 `family_id / qty / uom / pack_size / field_evidence / match_source / issue_code / reason_code`）、`conditions`、`ai_mode`、`ignored_spans`。
- **AI 永不产出**：`sku_id / unit_price / available_qty / sufficient / target_line_ids / blocking / resolved / draft_id / condition_id`（已用单测锁定，四个 dataclass 交集为空）。

若 He 确实需要 HTTP 边界，正确做法是他在自己的 `/orders/parse-draft` 里调用，**不是**新增公共路径。

## 4. 返回语义（He 的第 11 条）

| 场景 | 行为 | `ai_mode` |
|---|---|---|
| LLM 正常返回 | 正常解析 | `LLM` |
| 超时 / 网络错误 | 自动降级 RapidFuzz | `FALLBACK`（`raw_error` 记录原因） |
| HTTP 非 200（含 5xx） | 自动降级 | `FALLBACK` |
| 非法 JSON / 缺 `choices` / 缺字段 | 自动降级 | `FALLBACK` |
| 模型返回 `rows: []` | **不降级**，返回空 lines | `LLM`（需 He 确认是否接受） |
| 部分行降级（span 定位失败等） | 逐行降级 | `MIXED` |
| 词表缺失且 fallback 失败 | 抛 `AiAndFallbackUnavailableError` → **503** `AI_AND_FALLBACK_UNAVAILABLE` | — |
| `masked_text` > 4000 码点 | **不调用 AI**，抛 `MessageTooLongError` → **422** `MESSAGE_TOO_LONG` | — |
