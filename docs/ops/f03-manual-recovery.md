# F03 前端人工恢复：审核材料

状态：**待独立复核与签署**。本文件记录实现者的验证，不代表审核通过。

## 接入范围

- 实时 API 草稿中，无候选的旧行可从当前租户的完整商品目录选择 SKU；零行及已有行草稿可补录人工商品行。目录不完整时禁选，目录加载失败时不回退到本地 Demo。
- 更换 SKU 后清除旧价格调整、别名缓存选择和本地价格条件决定，并要求重新确认数量。新增行使用唯一 `client_line_ref`，保存成功后以服务端响应的新 `line_id` 和版本继续编辑。
- 保存前不显示新选 SKU 的价格、库存或小计。保存成功后采用完整服务端响应；价格条件需在服务端分配新行 ID 后重新绑定。没有保存的变更保留离开保护。
- 保存结果可能不确定时锁住再次提交，先读取最新草稿；若该 `client_line_ref` 已存在，阻止保留本地新增行重发。待批及终态依据 `allowed_actions` 锁定。

## 实现者验证

2026-10-31，在 `frontend/` 使用 Node 22 执行 `npm test`：78/78 通过；执行 `npm run build`：通过，冻结类型检查通过。

使用仅含合成商品和客户的本地 API 浏览器验收：零行补录、无候选旧行改选、添加后删除旧行、保存前隐藏价格和库存、保存后显示服务端价格与库存、未保存离开保护均通过。模拟“服务端已写入但浏览器连接中断”：页面禁用再次保存；读取最新草稿后，检测到相同 `client_line_ref` 并阻止重复新增；放弃本地编辑后显示已保存新行。检查了 1440、768、390px 宽度，390px 商品目录弹窗无横向溢出。

该浏览器验收使用临时合成服务，不是正式后端或演示库写入测试；B03 后端验收见 [接入契约](b03-manual-recovery.md)。本次未声称正式业务数据、正式 TEST32 或独立审核已通过。
