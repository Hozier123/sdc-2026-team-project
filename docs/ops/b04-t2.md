## Windows 新建本地环境辅助工具

`tools.verify_t2_local` 使用指定的 PostgreSQL 17 Windows 二进制，创建新的临时回环 cluster、UTF8 业务库和 API，加载 canonical seed，依次执行 T2 四例及附加 409/404 检查，保存逐 SKU、DO 和审计证据，结束时停止它创建的 API/PG。该工具不复位既有数据库，也不能替代 B05。

```powershell
python -m tools.verify_t2_local --postgres-bin '<PostgreSQL bin directory>' --tokens-file '<private role-token JSON>' --cluster-encoding EUC_CN
```

`--cluster-encoding` 可为 UTF8（默认）或 EUC_CN；业务数据库始终显式 UTF8。中文 Windows initdb 的已记录兼容问题可用 EUC_CN cluster 处理，不能据此宣称所有平台均验证通过。其他平台可使用驱动连接自行准备的专用 API，此 Windows 辅助工具不是必需依赖。

私密 token JSON 的结构按租户和种子 user_id 索引，例如 `T1 → USR_T1_CLERK`、`T2 → USR_T2_OWNER`；需包含 canonical seed 中全部用户的会话，工具验证其哈希与种子一致。不要提交该文件或明文会话。模型凭据与 endpoint 不参与这次 FALLBACK 运行。

默认生成的 `.tmp/` 和 `evidence/b04-runs/` 不入 Git。历史验证使用的完整应用快照与逐文件哈希私下留档；新运行须记录自己的源码版本，不能沿用历史签收。
